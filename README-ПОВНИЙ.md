# 💼 AI Фінанси

**Заміни фінансиста системою на штучному інтелекті.**

Скидаєш банківську виписку (PDF або CSV) — AI за 30 секунд розносить усі транзакції по категоріях, рахує прибуток, показує дашборд і відповідає на питання про твої фінанси.

```
Банківська виписка (PDF/CSV)
        │
        ▼
   🤖 AI категоризує транзакції (14 категорій)
        │
        ├──▶ 📊 Дашборд: KPI, графіки, аномалії, пошук
        ├──▶ 💬 AI-чат: «Скільки я витратив на рекламу?»
        ├──▶ 📅 Щомісячний P&L-звіт у Telegram — автоматично
        └──▶ 📋 Експорт у Google Таблицю (опція)
```

## 🚀 Швидкий старт (Docker) — 5 хвилин

### Крок 0. Встанови Docker Desktop

Якщо ще немає — скачай з [docker.com](https://www.docker.com/products/docker-desktop/) і встанови (потрібно один раз).

### Крок 1. Склонуй репозиторій

```bash
git clone git@github.com:ValentynS96/aiforpeople_finance.git
cd aiforpeople_finance
```

### Крок 2. Створи конфіг

```bash
cp bot/.env.example .env
```

Відкрий файл `.env` у будь-якому редакторі та заполни **три значення** (див. «Де взяти ключі» нижче):

```env
ADMIN_PASSWORD=твій_пароль_адмінки
SECRET_KEY=будь-яка_випадкова_строка
TELEGRAM_BOT_TOKEN=токен_від_BotFather
DEEPSEEK_API_KEY=ключ_з_DeepSeek
```

### Крок 3. Запусти

```bash
docker-compose up -d --build
```

Перша збірка — 5–10 хвилин (качаються бібліотеки AI). Далі —

```bash
docker-compose logs -f   # подивитись логи
```

Коли побачиш `Uvicorn running on http://0.0.0.0:8000` — **система працює**:

| Адреса | Що це |
|---|---|
| http://localhost:8000 | 📊 Дашборд (вхід за номером рахунку IBAN) |
| http://localhost:8000/admin | ⚙️ Адмінка (пароль = `ADMIN_PASSWORD`) |
| Твій бот у Telegram | 🤖 Надішли йому PDF-виписку |

### Крок 4. Перевір, що працює

1. Відкрий Telegram → знайди свого бота → `/start`
2. Надішли будь-який PDF або CSV виписку
3. Через 10–30 секунд бот надішле зведення: дохід, витрати, прибуток, категорії
4. Відкрий http://localhost:8000 → введи IBAN (з виписки) → бачиш дашборд

🎉 Готово. Далі просто надсилай виписки — дані копитимуться.

## 🔑 Де взяти ключі

### Telegram Bot Token

1. У Telegram знайди [@BotFather](https://t.me/BotFather)
2. Надішли `/newbot` → придумай ім'я та username
3. BotFather надішле токен виду `123456789:AAE...` — скопіюй у `.env`

### DeepSeek API Key (мозок системи)

1. Зареєструйся на [platform.deepseek.com](https://platform.deepseek.com/)
2. Розділ **API Keys → Create new key**
3. Скопіюй ключ `sk-...` у `.env`
4. Поповни баланс ($2–5 вистачить на місяці аналізів)

> 💡 Обидва ключі можна змінити пізніше без перезапуску — через адмінку (розділ «Ключі API»).

## 📖 Як користуватись

### Telegram-бот

| Команда | Що робить |
|---|---|
| `/start` | Довідка |
| `/summary` | Зведення по всіх твоїх рахунках |
| `/report` | P&L-звіт за минулий місяць |
| `/accounts` | Список твоїх рахунків |
| `/reset` | Очистити історію чату |
| 📎 Надіслати PDF/CSV | Проаналізувати виписку |
| ✍️ Написати текстом | Запитати AI про свої фінанси |

### Дашборд (http://localhost:8000)

- **Вхід** — номером рахунку (IBAN, формат `UA` + 27 цифр)
- **Фільтри** — період, місяць, рік, категорія
- **Пошук** — над таблицею транзакцій (напр. «Приватбанк»)
- **Завантаження** — перетягни PDF прямо на сторінку
- **Вкладка «Історія чату»** — усі бесіди з AI + пошук по них

### Адмінка (http://localhost:8000/admin)

Тут налаштовується все — **без редагування коду**:

- 🚨 **Пороги алертів** — коли вважати витрату аномальною
- 🏷 **Категорії** — свій список (AI підлаштується)
- 🧠 **Модель AI** — вибір моделі DeepSeek
- 🔑 **Ключі API** — заміна токенів (зберігаються зашифрованими)
- 📋 **Google Sheets** — підключення експорту
- 📅 **Автоматизації** — ручний запуск місячного звіту
- ⚠️ **Керування даними** — видалення даних рахунку (під пароль)

## ❓ Часті питання

**Бот не відповідає на файл.**
Перевір `TELEGRAM_BOT_TOKEN` у `.env` і логи: `docker-compose logs -f`. Інший бот з цим же токеном? Токен може працювати тільки в одному місці.

**«AI не налаштований» у відповіді.**
Не заданий ключ DeepSeek — додай через адмінку (розділ «Ключі API») або у `.env` + перезапуск.

**PDF не розпізнається.**
Скоріш за все це скан без текстового шару. Спробуй CSV-виписку з банку (приват24/monobank вміють експортувати CSV).

**Де мої дані?**
Усі в `data/data.db`. Бекап = скопіювати цей файл. Видалити дані рахунку — адмінка → «Керування даними».

**Як зупинити/перезапустити?**
```bash
docker-compose stop     # зупинити (підніметься при перезавантаженні ПК)
docker-compose start    # запустити назад
docker-compose down     # зупинити повністю
```
