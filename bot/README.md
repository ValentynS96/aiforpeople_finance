# 📊 AI замість фінансиста — бот + дашборд + адмінка

Telegram-бот + інтерактивний веб-дашборд + адмінка з налаштуваннями. Бот читає банківську виписку, розносить транзакції по категоріях через DeepSeek, а дашборд показує метрики, графіки й аномалії в реальному часі. Адмінка дозволяє змінюти пороги, категорії й ключі через UI — без правки коду.

Без n8n. Один Python-процес. Дані в SQLite.

---

## Архітектура

```
Юзер шле виписку в Telegram
  → DeepSeek категоризує (ключ з БД або .env)
  → зберігає в SQLite (db_bridge)
  → рахує метрики + аномалії (пороги з адмінки)
  → відповідь у чат

Дашборд (http://localhost:8000)          Адмінка (/admin, за паролем)
  → читає з SQLite                        → пороги алертів
  → KPI + графіки Chart.js                → категорії
  → фільтри (дата/категорія)              → ключі API (зашифровано)
  → таблиця транзакцій                    → історія завантажень
                                          → експорт у Google Sheets
```

**Один процес**: `uvicorn server.app:app` піднімає і дашборд, і бота (через lifespan). Бот працює в фоні, сервер обслуговує UI.

## Швидкий старт (10 хвилин)

### 1. Залежності
```bash
pip install -r bot/requirements.txt
```

### 2. Конфіг — створи `.env`
```bash
cp bot/.env.example .env
```
Мінімум для старту (решта — через адмінку):
```env
ADMIN_PASSWORD=admin           # пароль адмінки
SECRET_KEY=будь-яка-рядок-тут  # ключ шифрування (не міняй потім!)
TELEGRAM_BOT_TOKEN=...         # від @BotFather
DEEPSEEK_API_KEY=sk-...        # від platform.deepseek.com
```

### 3. Запуск (дашборд + бот в одному процесі)
```bash
PYTHONPATH=. uvicorn server.app:app --reload
```
- 📊 **Дашборд:** http://localhost:8000
- ⚙️ **Адмінка:** http://localhost:8000/admin (пароль з `ADMIN_PASSWORD`)

Якщо `TELEGRAM_BOT_TOKEN` не заданий — бот не стартує, але дашборд працює.

### 4. Тільки бот (без дашборда)
```bash
python bot/bot.py
```

## Адмінка — 4 розділи

| Розділ | Що робить |
|---|---|
| 🚨 **Пороги алертів** | Касовий розрив (вкл/викл), % перевитрати категорії, × податки, % зарплати. Зміна впливає на наступні виписки одразу. |
| 🏷️ **Категорії** | Список 8 категорій (по одній на рядок). Додати/перейменувати/видалити. |
| 🔑 **Ключі API** | DeepSeek, Telegram, Google JSON. **Шифруються** Fernet перед записом у БД. Порожнє поле не затирає. |
| 📋 **Експорт Sheets** | ID таблиці + чекбокс. Кнопка «Експортувати зараз» для кураторів. |
| 📜 **Історія** | Хто/коли завантажував виписки (chat_id, username, к-сть транзакцій). |

> **Безпека:** адмінка за паролем (cookie-сесія 7 днів). Секрети в БД зашифровані — навіть при витоку `data.db` ключі нечитаемі без `SECRET_KEY`.

## Дашборд — що бачить користувач

1. **4 KPI-картки**: Виручка 🟢 / Витрати 🔴 / Прибуток 🔵 / Маржа 🟣
2. **Donut**: витрати за категоріями
3. **Bar+Line**: дохід vs витрати по тижнях + тренд прибутку
4. **Панель алертів**: аномалії червоним блоком
5. **Таблиця транзакцій**: останні 100, з пагінацією
6. **Фільтри**: період (від/до) + категорія — оновлюють усі графіки

## Демо на вебінарі

1. Запусти: `uvicorn server.app:app` (або задай ключі в адмінці)
2. Надішли боту текст виписки → отримай зведення + алерт
3. Відкрий дашборд → побачиш свіжі дані й графіки
4. У адмінці зміни поріг → наступна виписка аналізується по-новому

**Тестові дані:** `test_bank_statement_250.csv` (250 транзакцій, 8 категорій).

## Структура
```
bot/
  ai_engine.py       DeepSeek + метрики + аномалії + summary
  sheets_writer.py   експорт у Google Sheets (gspread)
  db_bridge.py       міст: бот ↔ SQLite (читає ключі/пороги, пише транзакції)
  bot.py             Telegram-обработчик + build_application() для lifespan
dashboard/
  db.py              SQLite: схема, CRUD, фільтри
  crypto.py          шифрування секретів (Fernet)
  auth.py            пароль адмінки, cookie-сесія
  routes.py          FastAPI: /api/* + /admin/*
  templates/         dashboard.html, admin.html, admin_login.html
  static/            style.css, dashboard.js
server/
  app.py             FastAPI + lifespan (бот) + StaticFiles + маршрути
```

## М'яка деградація (важливо для ефіру)
- **Немає Google ключа** → метрики й алерти працюють, без експорту в Sheets
- **Немає DeepSeek** → бот повідомить (критично — без AI демо не іде)
- **Бот без токена** → дашборд і адмінка працюють, можна вручну додати транзакції
