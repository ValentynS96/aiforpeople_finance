# 💼 AI Фінанси — твій особистий фінансовий аналітик

Система, яка читає банківські виписки (PDF/CSV), категоризує кожний платіж
за допомогою ШІ і дозволяє **питати свої фінанси простою мовою**:

> «Скільки я витратив на рекламу?» · «Скільки заплатив ЄП?» ·
> «Порівняй останні два місяці» · «Які аномалії у витратах?»

Працює **повністю на твоєму комп'ютері**: виписки й ключі нікуди не
надсилаються, крім запитів до ШІ, який ти сам обереш.

---

## 🚀 Встановлення за 3 кроки

### Крок 1. Встанови Docker Desktop (один раз)

Скачай з [docker.com](https://www.docker.com/products/docker-desktop/),
встанови та **запусти** (кит у треї має бути активним).

### Крок 2. Запусти систему

**Подвійний клік:**
- 🖱 Mac → файл `START.command`
- 🖱 Windows → файл `START-WINDOWS.bat`

Перший запуск збирає систему ~5–10 хвилин. Браузер відкриється сам.
(Наступні запуски — ~10 секунд.)

**Або однією командою в терміналі** (у папці проєкту):

```bash
docker compose up -d --build
```

### Крок 3. Налаштуй ШІ (1 хвилина, єдине налаштування)

Відкрий **http://localhost:13500** — система сама відкриє майстер.
Обереш, хто буде аналізувати твої виписки:

| | 🔵 Google (рекомендовано) | 🟠 DeepSeek |
|---|---|---|
| **Конфіденційність** | 🛡 На платному тарифі Google **не навчає моделі на твоїх даних** | ⚠ За політикою DeepSeek дані з API **можуть використовуватись для навчання** моделі |
| **Вартість запитів** | 💰 **$0** — робоча модель Gemma 4 не тарифицується через API | платно за токени |
| **Ключ** | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → «Create API key», потім **поповни баланс на $5** — платний тариф (Tier 1) активується автоматично | [platform.deepseek.com](https://platform.deepseek.com/api_keys) → «Create new key» (поповни баланс на $2–5) |

> 💡 Навіщо $5, якщо запити безкоштовні? Саме платний тариф Google дає
> гарантію «дані **не** використовуються для навчання моделей» (безкоштовний
> тариф цього не гарантує). $5 лежать на балансі і не витрачаються — робота
> іде на безкоштовній Gemma 4. Хочеш розумнішу модель — перемкни на
> Gemini 3.5 Flash у ⚙️ Налаштуваннях (вона вже платна).

Встав ключ → натисни «Перевірити ключ» → «Почати роботу». Готово! 🎉

## 📱 Що далі

1. **Увійди за номером телефону** — це і є вхід. Без паролів і SMS:
   кабінет створюється автоматично при першому вході.
2. **Перетягни банківську виписку** (PDF або CSV) у вікно — ШІ розпізнає
   й категоризує всі транзакції за 1–3 хвилини.
3. **Питай що завгодно** в чаті або дивись метрики на дашборді.
4. (Опційно) **Telegram-бот**: створи бота у [@BotFather](https://t.me/BotFather)
   → `/newbot`, встав токен у ⚙️ Налаштування — і надсилай виписки/питай прямо в Telegram.

> ℹ️ Якщо у виписці за обраний період немає жодної операції — це не помилка:
> рахунок усе одно додається у кабінет з позначкою «операцій немає».

## 🤖 Telegram-бот

Надішли боту виписку (PDF/CSV) — він обробить її і додасть у твій кабінет.
Питання можна писати звичайним текстом. Команди:

| Команда | Що робить |
|---|---|
| `/start` | Привітання; при першому запуску бот попросить поділитися номером телефону — так Telegram прив'язується до того ж кабінету, що й на сайті |
| `/summary` | ШІ-зведення по рахунках кабінету |
| `/accounts` | Список рахунків з короткою статистикою |
| `/report` | P&L-звіт за минулий місяць |
| `/reset` | Очистити історію чату (транзакції залишаються) |

**Щомісячний звіт:** 1-го числа о 09:00 бот сам надсилає P&L-звіт за
минулий місяць по кожному рахунку (рахунки без операцій пропускаються).

## ⚙️ Налаштування

Кнопка **⚙️ Налаштування** у дашборді (або `http://localhost:13500/admin`):
зміна провайдера й моделі ШІ, ключі, Telegram-токен, список користувачів,
статистика витрачених токенів, видалення даних рахунку.

Паролів у системі немає взагалі — вона працює на твоєму комп'ютері,
тому доступ до неї = доступ до твого комп'ютера.

**Вхід за IBAN (демо-режим):** ⚙️ Налаштування → Користувачі →
«Дозволити вхід за IBAN без телефона». За замовчуванням вимкнено —
дані доступні лише за номером телефону.

## ❓ Часті питання

**Як зупинити систему?** `docker stop ai-finansy` (або закрий Docker Desktop).
Запуск — знову подвійний клік по `START`.

**Де зберігаються мої дані?** У папці `data/` всередині проєкту (SQLite).
Бекап = скопіювати цю папку. Видалити все — видалити папку `data/`.

**Порт 13500 зайнятий / хочу інший порт?** Зміни перше число в
`docker-compose.yml`: `"13500:8000"` → `"13600:8000"` і перезапусти.

**Ключ закінчився / змінився?** ⚙️ Налаштування → Ключі API — бот
перезапуститься автоматично.

**Бот не відповідає?** Перевір, що Docker Desktop запущений, потім:
`docker logs -f ai-finansy`

**Скинути все до чистого аркуша?** Зупини систему, видали папку `data/`,
запусти знову — майстер налаштування почнеться спочатку.

## 🛠 Для розробників

- **Стек:** FastAPI + Jinja2 + SQLite (FTS5) + python-telegram-bot, Docker.
- **Порти:** зовнішній `13500` → контейнер `8000`.
- **Структура:** `server/` — FastAPI і парсинг виписок · `dashboard/` —
  веб-дашборд, налаштування, БД · `bot/` — Telegram-бот і рушій ШІ
  (провайдери Google Gemini / DeepSeek, обидва через OpenAI-сумісний API) ·
  `scripts/` — генератор демо-виписки в PDF (`python3 scripts/generate_statement.py`).
- **Автоматизації:** щомісячний P&L-звіт у Telegram — `server/scheduler.py` (APScheduler).
- **Збірка на старих машинах:** якщо BuildKit падає з таймаутом —
  `DOCKER_BUILDKIT=0 docker compose build`.
