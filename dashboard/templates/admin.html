🚨 Пороги алертів

Зміна порогів одразу впливає на аналіз наступних виписок (без перезапуску).

Тривога, якщо за період витрати перевищили дохід (прибуток < 0). Розрахунок: дохід мінус витрати за всіма транзакціями періоду.

Тривога, якщо одна категорія (напр. реклама) займає ≥ 30% усіх витрат. Розрахунок: витрати категорії ÷ загальні витрати × 100.
Тривога, якщо податки ≥ 3× середньої категорії витрат. Розрахунок: витрати на податки ÷ (загальні витрати ÷ кількість категорій).
Тривога, якщо зарплати з'їдають ≥ 80% доходу. Розрахунок: витрати на зарплати ÷ дохід × 100.

📖 Як підключити Google-таблицю (4 кроки)
  1. У Google Cloud Console створіть проєкт → увімкніть Google Sheets API та Google Drive API
  2. IAM → Service Accounts → Create → відкрийте акаунт → Keys → Add Key → JSON → скачайте файл
  3. У своїй Google-таблиці натисніть «Поділитися» → додайте email сервіс-аккаунту (поле client_email у JSON) → роль «Редактор»
