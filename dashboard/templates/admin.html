📖 Як підключити Google-таблицю (4 кроки)
  1. У Google Cloud Console створіть проєкт → увімкніть Google Sheets API та Google Drive API
  2. IAM → Service Accounts → Create → відкрийте акаунт → Keys → Add Key → JSON → скачайте файл
  3. У своїй Google-таблиці натисніть «Поділитися» → додайте email сервіс-аккаунту (поле client_email у JSON) → роль «Редактор»
  4. Скопіюйте вміст JSON-файлу ↓ у поле нижче, а ID таблиці — з URL (довгий код між /d/ і /edit)
